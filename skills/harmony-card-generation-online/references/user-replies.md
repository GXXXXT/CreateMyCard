# 固定回复与用户可见信息规范

执行前读取一次本文档。所有用户可见回复按编号选择模板，仅替换允许的占位符；不得自由改写、透传工具 message 或拼接内部解释。主流程负责规定发送时点，本文档是 Skill 内话术全文的唯一维护位置。

## 模板表

| 编号 | 使用条件 | 固定话术 |
| --- | --- | --- |
| R01 | create 首个工具调用前，仅一次 | 好的，我现在为你创建卡片。 |
| R02 | edit 首个工具调用前，仅一次 | 好的，我现在按你的要求修改卡片。 |
| R03 | 卡片意图仍有歧义 | 你希望把{需求概括}做成桌面卡片吗？ |
| R04 | 无法确定编辑对象 | 你想修改哪张卡片？ |
| R05 | 缺少修改内容、用户偏好或有歧义的业务目标 | 请补充{一个最小必要信息}。 |
| R06 | 非卡片或不适合卡片承载 | 桌面卡片适合展示少量关键信息或提供快捷入口，暂不适合处理你这次的{需求类型}。你可以试试：{相近需求} |
| R07 | 核心能力缺失或生成返回 unsupported | 抱歉，当前卡片能力暂无法满足你需要的{缺失内容}。你可以试试：{相近需求} |
| R08C | create 次要内容不可用或次要来源失败 | 当前暂无法提供{缺失内容}，我会移除该内容并基于其余可用内容继续为你创建卡片。 |
| R08E | edit 次要内容不可用或次要来源失败 | 当前暂无法提供{缺失内容}，我会移除该内容并基于其余可用内容继续为你修改卡片。 |
| R09 | 可用替代改变主要用途，等待确认 | 当前暂无法提供{缺失内容}。是否改为{已确认可用的替代用途}？ |
| R10 | 编辑超出支持范围 | 当前连续编辑暂不支持{本次修改内容}，这次先不修改。你可以重新创建一张卡片，例如：“{重新创建需求}” |
| R11 | 需要手动授权且有设置路径 | 请前往「{设置路径}」，为「{授权项名称}」开启权限，然后再试。 |
| R12 | 需要手动授权但无设置路径 | 请为「{授权项名称}」开启权限，然后再试。 |
| R13 | 明确拒绝且无有效授权明细 | 当前生成卡片所需的数据权限不可用，已停止生成。 |
| R14 | 必要工具异常、非法结果、无法恢复编辑来源或无合法新产物 | 卡片创建过程遇到问题了，请稍后再试 |
| R15 | 每个外部来源调用前 | 正在调用「{来源显示名}」获取{用途}。 |
| R16 | 每个外部来源校验、回填后，下一来源调用前 | 已从「{来源显示名}」获取到：{已校验且将采用的事实摘要}。 |
| R17 | 核心来源失败或事实无法可靠校验 | 暂时无法获取{核心内容}，这次先不生成卡片。 |
| R18C | create 完整成功 | 已为你生成一张{用途}卡片，内容包括{内容概括}。 |
| R18E | edit 完整成功 | 已按你的要求修改为一张{用途}卡片，内容包括{内容概括}。 |

| 编号 | 已确认的缺失类型 | 固定追加句 |
| --- | --- | --- |
| R19D | 数据 | 本次未包含{缺失内容}数据，已按其余可用内容生成。 |
| R19A | 动作 | 本次未提供{缺失内容}操作，已按其余可用内容生成。 |
| R19M | 用户所需素材 | 本次未使用{缺失内容}素材，已按其余可用内容生成。 |
| R19X | 多类混合或不能细分 | 本次未包含{缺失内容}，已按其余可用内容生成。 |

## 占位符与组合规则

- 不输出编号、占位符名称或大括号。只有 R11/R12 的多项授权引导和 R18 + R19 的部分满足允许组合，其它情形每次选择一个对应模板。
- 澄清只选 R03/R04/R05/R09 中一个，询问一个用户可回答的问题并等待；不向用户询问技术字段、设备是否支持或权限状态。
- 缺失内容使用用户原话中可确认的内容，以本轮能力裁决、来源失败或服务移除结果核对；多个名称按原顺序去重，以“、”连接，无法可靠提炼时使用“相关内容”。
- 相近需求为 1～3 条用引号包围、顿号分隔的可复述请求。已有合法概述时从实际候选提炼；尚无概述时只用天气、日程、运动、设备电量或系统状态通用示例，不承诺可用。工具异常使用 R14，不追加推荐。
- R10 描述具体不支持的修改，例如“将天气替换成日历数据”“修改点击动作”，不把所有替换都说成新增。重新创建需求仅供用户下一轮主动发起，不自动执行。
- 授权名称、设置路径只取正常权限返回中的合法明细；同名保留第一项，逐行发送 R11/R12，不追加建议。明细非法使用 R14，不猜测路径。
- 来源显示名和用途取运行时元数据或其安全自然语言概括，不能用内部工具名称、包名或 Skill 标识。显示名/用途无法安全取得时视为来源不可用。
- 事实摘要只包含当前来源已校验且确定用于参数或有效需求的简短事实；保留必要的地点、日期、时区、单位和不确定性，不输出未采用内容、未经证实的推测、原始响应或链接。每个成功来源均在校验、回填后立即发送 R16。
- 用途和内容概括来自本轮有效需求、校验后的来源事实、用户明确静态要求；edit 可结合真实编辑链中的保留需求作概括，不声称某个字段或动作已经实际渲染。用户需求摘要不足时使用保守的用途概括。
- 必要工具失败使用 R14；核心外部来源失败使用 R17；次要来源失败使用 R08C/R08E。权限 invoke 级异常不发送任何异常话术，继续执行后续步骤。

## 发送前检查

1. 不含产物 URL、来源链接、Markdown URL、结果代码块或替代结果标记。
2. 不含能力 ID、schema、provider、TaskSpec、CardSpec、DSL、OBS、IDS、错误码、请求 ID、工具包络、内部草稿或敏感信息。
3. 不透传或润色业务 message；不宣称已添加到桌面、已安装、已开启权限或其它未执行操作。
4. 开始处理不表示成功，来源事实不表示卡片已生成，成功只表示生成并交给端侧预览。
