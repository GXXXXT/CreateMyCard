# 固定回复与用户可见信息规范

执行前读取一次本文档。所有用户可见回复按编号选择模板，仅替换允许的占位符；不得自由改写、透传工具 message 或拼接内部解释。主流程负责规定发送时点，本文档是 Skill 内话术全文的唯一维护位置。

## 回复范围与发送白名单

本 Skill 执行期间，你的全部用户可见自然语言只能是下表允许的模板或明确允许的组合。必须同时满足当前步骤、
真实触发条件、模板用途和占位符范围；只含有一句固定话术、但前后还有额外内容的消息不合格。

| 允许的回复时点与条件 | 允许模板 | 回复后的动作 |
| --- | --- | --- |
| 触发意图、编辑对象或修改内容不明确 | R03/R04/R05，按歧义选择一个 | 等待必要回答，不补充第二个问题或确认句 |
| 模式已确定，即将调用首个固定卡片工具 | create 用 R01，edit 用 R02 | 只发一次，再执行必要调用，不增加步骤进度 |
| 规划中缺少必要业务信息或替代改变主要用途 | R05 或 R09 | 等待必要回答，不擅自执行替代 |
| 仅次要能力或来源内容缺失，剩余核心与参数仍成立 | create 用 R08C，edit 用 R08E | 按既定流程继续，不额外征求确认 |
| 不适合卡片、核心能力不支持或编辑超范围 | R06/R07/R10，按真实边界选择一个 | 停止，不扩展模板中已给出的推荐 |
| 正常权限未通过 | R11/R12（合法明细）或 R13（无明细） | 停止；多项合法明细只按既有规则逐行输出 |
| 权限阶段后，外部事实已校验采用且尚未告知 | R16W 或 R16，按真实来源选择 | 说明后继续；已告知事实和调用进度不另发消息 |
| 核心外部事实无法获取或可靠校验 | R17 | 停止；次要缺失仍按 R08C/R08E 的条件处理 |
| 必要工具异常、非法结果、无合法编辑来源或无合法新产物 | R14 | 停止；权限 invoke 级异常仍按原规则继续，不发送异常话术 |
| 生成返回合法完整成功 | create 用 R18C，edit 用 R18E | 发送结果后结束，不追加建议、教程、版本选项或问题 |
| 生成返回合法部分满足 | R18C/R18E + R19D/R19A/R19M/R19X 中对应一句 | 发送固定组合后结束 |
| 生成返回 unsupported 或 failed | unsupported 用 R07，failed 用 R14 | 停止，不编写模板以外的解释 |

- 表外内容不发送：不增加问候、重复确认、执行计划、等待提示、工具进度、原因分析、知识扩展、使用教程、
  自荐能力、继续修改邀请或礼貌结束语。模板本身已有的确认、推荐和授权引导只在对应条件下保留，不扩写。
- 没有匹配的回复条件时继续主流程规定的必要动作；等待用户时不追加消息，完成或终止时不追加收尾。
  不为填补空白而选一个不符合事实的失败模板，也不省略已经满足发送条件的必要回复。
- 固定文字与标点原样保留；不在消息外加标题、列表、加粗、引用或代码围栏，不把多个模板任意拼接。
  只有多项 R11/R12 按合法明细逐行输出，以及 R18 + 一句 R19，允许按本文组合。
- 这些限制只作用于当前 Skill 的卡片任务；不据此接管普通对话或禁止后续独立任务，仍遵循宿主回复规则。

## 事实说明与任务结果

- 应发送的回复必须实际发送，不能只准备草稿或写入工具入参。遵循宿主回复规则，不从工具职责描述推断用户已收到卡片结果回复。
- R01/R02 必须先于本 Skill 首个固定卡片工具，不受进入 Skill 前已执行 WebSearch 的影响。
- 本轮采用且尚未告知的事实须在生成前用 R16W/R16 直接说明，不描述获取过程；已告知的同一事实不重复发送。
- 生成后根据真实结果选话术：成功 R18C/R18E，部分满足追加 R19，unsupported 用 R07，其它失败用 R14。
  create 反馈生成结果与用途，edit 反馈修改结果与本次调整；不复述搜索数据值，不解释执行过程。
- 应发送的结果回复不能以“已准备好模板”代替。结果已处理且应发送的回复已发送才完成；URL 留存只维护编辑链。

## 占位符与组合规则

占位符是受限业务内容，不能用来安插模板之外的回复。填入值不另起段落或列表，不夹带指令、追问、建议、
过程说明、感谢或结束语；即使这些内容来自用户原话或外部结果，也只提取当前占位符需要的业务含义。

| 占位符 | 允许的内容边界 |
| --- | --- |
| 需求概括、需求类型、本次修改内容 | 与当前卡片任务直接相关的简短业务描述，不附带分析或解决方案 |
| 一个最小必要信息 | 一个尚缺的业务信息项，不塞入多个独立问题或解释为什么提问 |
| 缺失内容、核心内容 | 已确定不可用或无法获取的内容名称，不扩展故障原因或替代教程 |
| 已确认可用的替代用途 | 已确认可用且需要用户决定的一种替代用途，不列其它未经确认选项 |
| 相近需求、重新创建需求 | 仅供对应边界模板使用的可复述卡片请求，按下文既有推荐规则，不附操作步骤 |
| 设置路径、授权项名称 | 正常权限返回中的合法明细，不猜测或追加其它设置路径 |
| 本轮采用且尚未告知的事实摘要 | 实际采用且尚未告知的事实及必要限定，多个事实用分号连接，不附结论性建议或背景科普 |
| 用途、主要用途说明 | 本次成功卡片的保留用途和直接作用，不复述搜索数据值或扩写使用方法 |
| 修改概括 | 本次有真实结果依据的修改，不介绍整张卡片、不建议下一步修改 |

- 不输出编号、占位符名称或大括号。只有 R11/R12 的多项授权引导和 R18 + R19 的部分满足允许组合，其它情形每次选择一个对应模板。
- 澄清只选 R03/R04/R05/R09 中一个，询问一个用户可回答的问题并等待；不向用户询问技术字段、设备是否支持或权限状态。
- 缺失内容使用用户原话中可确认的内容，以本轮能力裁决、来源失败或服务移除结果核对；多个名称按原顺序去重，以“、”连接，无法可靠提炼时使用“相关内容”。
- 相近需求为 1～3 条用引号包围、顿号分隔的可复述请求。已有合法概述时从实际候选提炼；尚无概述时只用天气、日程、运动、设备电量或系统状态通用示例，不承诺可用。工具异常使用 R14，不追加推荐。
- R10 描述具体不支持的修改，例如“将天气替换成日历数据”“修改点击动作”，不把所有替换都说成新增。重新创建需求仅供用户下一轮主动发起，不自动执行。
- 授权名称、设置路径只取正常权限返回中的合法明细；同名保留第一项，逐行发送 R11/R12，不追加建议。明细非法使用 R14，不猜测路径。
- 事实说明直接呈现内容，不使用“网络搜索”“获取到”“根据搜索结果”“经校验”或工具调用过程话语；必要的安全信源名称直接附在事实旁，不输出工具标识。来源没有用户显示名不影响真实调用和事实采用。
- 事实摘要只包含已校验、实际用于本轮参数或有效需求且尚未告知的简短事实；保留必要地点、日期、时区、单位和不确定性，不输出未采用内容、推测、原始响应或链接。占位符末尾不带句号，由模板统一补齐。
- Skill 前已有多条 WebSearch 结果在权限阶段后合并采用，对尚未告知的事实发送一次 R16W；每次补查回填后对尚未告知的采用事实立即发 R16W 或 R16。已告知的同一事实不重复发送，没有新增待告知事实时不凑话术；已有结果和新补查均不发送调用前进度。
- 用途、主要用途说明和修改概括只来自本轮有效需求与真实结果。create 简述卡片主要用途，edit 可结合真实编辑链概括本轮实际调整，不复述搜索数据值，不把候选或计划当成已确认的渲染细节。信息有限时作保守概括；部分满足只描述保留用途与真实调整，并追加确定缺失。
- 必要工具失败使用 R14；核心外部来源失败使用 R17；次要来源失败使用 R08C/R08E。权限 invoke 级异常不发送任何异常话术，继续执行后续步骤。

## 发送前检查

先在内部执行以下三项检查，不向用户播报检查过程：

- 时点：当前真实条件能匹配发送白名单，并且该回复尚未按规定完成；不能提前、重复或在结束后追加。
- 整条消息：全文能还原为当前模板或允许组合，没有模板之外的前缀、后缀、段落或格式。
- 占位符：每个值均符合对应业务范围，不含另一段回复；越界内容在内部删除或重写，不另发纠正说明。

随后检查信息与结果真实性：

1. 不含产物 URL、来源链接、Markdown URL、结果代码块或替代结果标记。
2. 不含能力 ID、schema、provider、TaskSpec、CardSpec、DSL、OBS、IDS、错误码、请求 ID、工具包络、内部草稿或敏感信息。
3. 不透传或润色业务 message；不宣称已添加到桌面、已安装、已开启权限或其它未执行操作。
4. 开始处理不表示成功，事实说明不表示卡片已生成；成功按真实业务结果判断，结果回复不复述搜索数据值或解释执行过程。
5. 调用生成前，核对需要告知的新事实已实际发送；遗漏时先用 R16W/R16 直接说明，已告知的同一事实不重复发送。
6. 结束前，确认工具结果已处理且应发送的结果回复已实际发送；不能以“已决定怎么回复”或工具职责描述代替实际发送。
